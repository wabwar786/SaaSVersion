Offline version

Offline software for the counter PC

This package runs on your store's PC. Billing, stock, credit accounts and receipts all work without the internet. When the connection returns, everything is sent to the cloud automatically. Your business name, branch and sync token are already sealed inside the package — there is nothing to configure.

How to install

On the counter PC, once

1
Download the ZIP and extract it

Into any folder on the counter PC — for example C:\RetailOS. Do not use a network drive.

2
START_RESTAURANT.bat — double-click it

The first run installs and prepares PHP, MariaDB and the database itself. It takes a few minutes and needs no command-line knowledge.

3
The browser opens by itself

The same email and password you were given online.

4
Connect the hardware

Barcode scanner (keyboard-wedge, no driver needed), receipt printer, cash drawer and label printer. Set them up in Printers & Devices .

5
Sync runs on its own

As soon as the internet is back, bills go up and the head-office catalogue comes down. Nothing to press.

Billing never stops. With no internet the bill is written to the local database and the receipt prints. As soon as the connection returns, that bill goes to the cloud. Bills travel upward only — they never come back down, otherwise two branches would erase one another bills.

Which modules run only offline

Some things are tied to the counter's hardware — the cloud simply cannot reach them

ModuleWhere it runsReason
Tax / Digital Invoice (FBR, PRA, KPRA) Offline only The FBR fiscal service runs on the same PC as the POS (localhost). The cloud cannot reach it.
Receipt printer & cash drawer Offline only The printer is attached to the counter PC by USB or serial. The drawer opens from that printer's kick command.
Barcode & shelf label printing Offline only A TSPL/ZPL label printer is a local device.
Weighing scale (live read) Offline only The scale is attached by serial or USB. A label printed by the scale scans on the cloud too — the weight is inside the barcode.
POS, stock, khata, GRN, reports Both On the node and in the cloud — the data stays in sync.
Offline version download Online only The package is built in the cloud because your sync token is sealed into it.
